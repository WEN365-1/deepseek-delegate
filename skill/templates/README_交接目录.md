## 环境的坑
- <例：Windows + Git Bash。Python 用 `python`，没有 `python3`。>
- <例：路径里有中文和空格，命令里一律加双引号。>
- 你能用的命令只有：python、ls、cat、head、tail、wc、date、git status/diff/log，以及文件读写工具。其他命令会被拒绝。被拒绝就如实写进回报，不要想办法绕过。

## 版本管理（git）
- 项目用 git 做本地快照。每轮开始前和审核通过后由主控提交。执行模型不做 commit / checkout / reset。
- 大文件（数据、权重、缓存、虚拟环境、压缩包）不进 git，见 `.gitignore`。

## 规则（不可违反）
- 只做指令写明的事。遇到指令没覆盖的情况，先停下，在回报里说明，不要自己扩大范围。
- 不准伪造结果。命令失败就如实贴出输出；跳过的步骤要写明跳过了，以及为什么。
- 回报里必须贴出关键命令的原始输出，不要只写"成功"。
- 禁止删除任何文件。指令没有明确授权时，禁止推送。
- 代码文件可以原地修改（git 会记录）。**数据文件、结果文件、日志只新建、不覆盖**：新文件用新名或加日期后缀。
- 只在项目根目录之内写文件。
