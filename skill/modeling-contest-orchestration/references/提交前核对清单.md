# 提交前核对清单（通用版）

> 每项都要有明确结论：PASS / FAIL / 不适用。FAIL 必须修完再提交。

## A. 论文本体

- [ ] 页数符合赛题要求；正文页数与附录分开统计
- [ ] 封面队号/文件名与报名编号一致
- [ ] 目录页码与正文一致（改动后重新生成）
- [ ] 无空白页、无孤立表头、无跨页断裂的表
- [ ] 所有图表有编号、题注、正文引用
- [ ] 三线表格式统一；续表有"续表"题注
- [ ] 公式编号连续，变量在首次出现处解释
- [ ] 摘要包含：问题、方法、关键数字、结论；数字与正文一致
- [ ] 参考文献：正文首次出现顺序 = 文末编号顺序；格式统一
- [ ] 局限与边界如实披露

## B. 匿名与合规

- [ ] 正文、图表、代码、文件名无队员姓名、学校、导师
- [ ] PDF/Word 元数据（作者、最后修改者、公司）已清理
- [ ] 附件 zip 内每个文件的元数据也扫描过
- [ ] AI 使用声明、AI 详情 PDF、附录三处口径一致
- [ ] AI 使用日期与日志一致
- [ ] AI 详情 PDF 本身匿名、可正常打开、页数正确

## C. 支撑材料

- [ ] 目录结构与论文/README 描述一致
- [ ] 每个脚本能 `ast.parse` 通过；关键脚本有运行说明
- [ ] `requirements.txt` 版本与实际环境一致
- [ ] 结果文件齐全（指标 json、预测 csv、图表源文件）
- [ ] 解压到干净目录后，按 README 能复现关键结果
- [ ] 无 `.venv`、`__pycache__`、临时文件、备份目录

## D. 提交动作

- [ ] 三件套齐全：论文 PDF、附件 zip、承诺书 PDF
- [ ] 承诺书为队员真实签名，非自动生成
- [ ] 文件名严格按赛题要求（如 `A2600780.pdf`）
- [ ] 单独要求的计算结果文档已上传（不能只传论文和代码）
- [ ] 上传后页面显示"电子档已提交"
- [ ] 已保存提交成功截图与文件哈希
- [ ] 提交后未再修改任何文件

## E. 赛后归档

- [ ] `00_最终提交/` 含三件套 + 提交说明（哈希、时间、AI 口径）
- [ ] `99_归档_过程材料/` 保留原目录结构
- [ ] 顶层 README 说明目录用途与重跑根目录
- [ ] 大备份/中间产物已按授权清理
