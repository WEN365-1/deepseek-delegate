# DeepSeek 交接目录约定

## 项目
- 根目录：`<项目根绝对路径>`
- 主控：Kimi；执行：DeepSeek（通过 DeepSeek API 和 `ds_run.py`）。
- Python 命令：`python`；路径包含中文或空格时必须加双引号。

## 文件
- `Kimi指令_YYYY.MM.DD.HH.MM.md`：本轮指令。
- `DeepSeek回报_YYYY.MM.DD.HH.MM.md`：本轮文字回报。
- `DeepSeek运行_YYYY.MM.DD.HH.MM.json`：状态、工具事件与 token 用量。
- `history/`：验收后的归档，执行方不要改动。

## 权限
- 默认只读；每轮可开放的能力以指令顶部“本轮权限”为准。
- 只能在项目根目录内操作，禁止访问 `.git` 和凭据文件。
- 新建文件默认不覆盖已有文件；允许覆盖时必须逐项列出路径。
- Python 执行不是安全沙箱；只能运行主控已审查且本轮明确允许的项目脚本。

## 规则
- 只做指令写明的事；未覆盖的情况停止并报告。
- 不伪造结果，失败或跳过必须如实说明并保留证据。
- 禁止删除、移动、重命名文件，禁止任何 Git 写操作。
- 不修改其他并行任务负责的文件，也不还原其改动。
